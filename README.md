# Mikael StoneBlock Lite 0.5.8 — livro reduzido para 500 missões

Minecraft 1.12.2 / Forge 14.23.5.2860.

## Alterações
- Reduzido o livro de FTB Quests de 1.335 para exatamente 500 missões.
- Mantidos os capítulos de sobrevivência, máquinas, Mekanism, energia, Extreme Reactors, ProjectE, Thermal, Botania e Mystical Agriculture.
- Removidas as 750 missões genéricas de coleção; Mystical Agriculture foi reduzido para 248 missões, mantendo introdução e objetivos de recursos mais úteis.
- Regenerados os índices do FTB Quests; corrigidos dois pré-requisitos que apontavam para missões inexistentes.
- Reorganizadas as posições do capítulo de Mystical Agriculture para evitar sobreposições.
