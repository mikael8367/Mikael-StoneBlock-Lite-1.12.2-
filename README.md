# Mikael StoneBlock Lite 1.12.2

Versão 0.2.0 — perfil CurseForge para Minecraft 1.12.2 / Forge 14.23.5.2860. Inclui mundo de pedra com ilha StoneBlock, progressão Ex Nihilo + Thermal e FTB Quests.

## Importação

Baixe `Mikael-StoneBlock-Lite-0.2.0.zip` e importe no CurseForge App ou launcher compatível com manifest CurseForge. Os mods são resolvidos pelos IDs CurseForge; os JARs não estão embutidos.

No single-player, crie um mundo novo com o tipo `Void? World` do Void Island Control. No servidor, `overrides/server.properties` define `level-type=voidworld` (settings devem ser aplicadas antes de gerar o mundo). As configs incluem geração de pedra/lava, ilha customizada e estrutura NBT inicial.

Inclui FTB Quests 1.9.0.11 + FTB Library, Item Filters e Forgelin; capítulo inicial de quests ainda precisa ser criado/testado no jogo.

**Ainda não testei a instalação nem criei o mundo no launcher do celular.** Arquivos/manifest validados não garantem runtime nem desempenho no Galaxy A12; o pack é bem menor que o StoneBlock completo mas pode ainda pesar no aparelho.
