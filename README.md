# Mikael StoneBlock Lite 0.5.4 — FTB Quests

Minecraft Java 1.12.2 / Forge 14.23.5.2860. OptiFine HD U G5 deve ser instalado separadamente; não está incluído.

## O que mudou
- 1.000 missões FTB Quests com 1.000 objetivos de item distintos (incluindo variantes/metadata), sem alvos duplicados.
- Todas têm tarefa e recompensa; há recompensas de itens e de experiência.
- Mantidas missões/capítulos de progressão, Thermal e Botania; cinco objetivos repetidos nas missões-base foram removidos.
- Arquivos SNBT, índices, contagem e unicidade conferidos. Ainda não testado dentro do launcher/jogo.
