# Mikael StoneBlock Lite 0.5.5 — Mystical Agriculture

## Alterações
- Adicionados Mystical Agriculture 1.7.5 e Cucumber Library 1.1.3, versões para Minecraft 1.12.2 Forge.
- Adicionado capítulo de Mystical Agriculture com 335 missões e recompensas.
- Mantidas as missões anteriores; o livro tem 1.335 missões no total e 1.335 alvos de item distintos (considerando a variante/metadata).
- As missões do capítulo novo conferem os itens contra os recursos do mod; os alvos do livro foram auditados para não repetir.
